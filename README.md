# 🔮 Futuris

Futuris is an AI-driven Android application developed as a university multidisciplinary project by a team of Computer and Communications Engineering students.

The application analyzes user-provided information to generate personalized, future-oriented insights and probabilistic predictions across different areas of life.

Rather than presenting predictions as certain outcomes, Futuris provides possible trends and scenarios together with confidence levels.

## 🎯 Project Objective

The main objective of Futuris is to design a conversational AI application capable of analyzing personal information provided by users and transforming it into meaningful future-oriented insights.

Users can provide information such as:

* Personal habits
* Previous experiences
* Opinions
* Interests
* Preferences
* Quiz responses
* Personal concerns and questions

The system analyzes this information and generates personalized predictions, trends, and possible future scenarios.

## ✨ Features

### 🤖 AI-Generated Insights

Futuris uses artificial intelligence to analyze user information and generate personalized insights based on the available data.

The system is designed to provide probabilistic results rather than presenting predictions as guaranteed outcomes.

### 💬 Conversational Interface

Users can interact naturally with the application through a chatbot-style experience.

The conversational interface allows users to ask questions, provide additional context, and explore personalized insights.

### 🧠 Personalized Analysis

The application uses information supplied by the user to produce more relevant results.

Analysis can take into account factors such as:

* User history
* Habits
* Preferences
* Opinions
* Quiz answers
* Previous interactions

### 📊 Probabilistic Predictions

Futuris can present:

* Possible future scenarios
* Trends
* Predictions
* Personalized observations
* Confidence levels

This approach helps communicate uncertainty instead of presenting AI-generated predictions as facts.

### 📱 Multiple Life Categories

### 📝 Interactive Quizzes

Quizzes allow the application to collect structured information from users and use their answers as additional input for personalized analysis.

* Protection of user privacy

## 🚀 Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/mahmoud-hachem/Futuris.git
cd Futuris
```

### 2. Open the project

Open the project in **Android Studio**.

### 3. Sync dependencies

Allow Android Studio and Gradle to download and synchronize the required dependencies.

### 4. Run the application

Select an Android emulator or connect an Android device, then run the application from Android Studio.

Some features may require access to the project's backend services.
